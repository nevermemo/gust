# Slang language

Preserve restricted Rust GPU module -> validated syn AST -> direct Slang emission -> slangc -> WGSL/SPIR-V. Slang's internal compiler IR is outside this project's frontend architecture.

1. Inspect the failing emitted shader, binding metadata, command, and installed slangc version (the project pins one release: `cargo gust slang install` puts it in `GUST_SLANG_HOME` or the default cache, `cargo gust slang locate` prints it, `cargo gust doctor` names a `slangc` of another version; `cargo xtask` and the run-time bridge launch plain `slangc` from `PATH`). Reduce the shader before changing the Rust emitter.
2. Keep entry point, compute stage, workgroup dimensions, resource access and bindings explicit. Match the host ABI.
3. Compile each requested target independently. Success for SPIR-V does not establish WGSL compatibility or runtime correctness.
4. Return the smallest shader/emitter fix, exact command and target-specific result.

Read [target and ABI notes](references/targets-and-abi.md) only for language/target decisions. Run `cargo xtask slangc <file.slang> --entry <name> --target wgsl|spirv --out <path>` for repeatable compilation: it refuses an existing output path, fails on a missing or empty artifact, and writes `<out>.command.json` (slangc version, arguments, output SHA-256) and `<out>.compile.log` beside the output. Extra slangc arguments go after `--`. The [smoke shader](assets/vector-add.slang) tests tool installation, not Rust lowering; `cargo xtask doctor --smoke` compiles it to both targets.

Workgroup memory (M7, m7.g1): a `Workgroup<[T; N]>` kernel parameter is emitted as `groupshared T name[N];` at module scope, once per parameter and under the parameter's own name, before the kernel; `workgroup_barrier()` is `GroupMemoryBarrierWithGroupSync();`; `SV_GroupThreadID` and `SV_GroupID` are not entry-point parameters but locals derived from the dispatch id (`uint3 lid = uint3(id.x % Xu, id.y % Yu, id.z % Zu)` and the same with `/`, X, Y, Z the declared `workgroup_size`). A `groupshared` array has no initialiser and starts unspecified. Golden: `tests/fixtures/workgroup.slang`.

Subgroup operations (M8, m8.s): the WGSL slangc writes for them is not accepted by wgpu 30 as it stands. `gust::slang::wgsl::fixup_subgroups` removes `enable subgroups;` (wgpu 5555) and rewrites the lane argument `i32(expr)` of `subgroupShuffle`/`subgroupBroadcast` to `u32(expr)`, a literal to `3u` (wgpu 10818); it is a text edit with no parse, identity on other text, and keeps CRLF. `compile_at_in` applies it to the WGSL it returns, so the run-time compiler and the reflected bridge are covered; `cargo gust build` applies `fixup_artifact`, which also replaces the `artifactHash` of the reflection document (the FNV-1a64 fingerprint of the stored bytes, which `verify_stored` checks). `WaveBroadcastLaneAt` needs a compile-time constant lane (E40012) and `WaveIsFirstLane` becomes `subgroupElect`, which naga lacks. The names `Wave*` are not covered by `slang/collisions.rs`: a user identifier spelled like an intrinsic is a documented limitation. Goldens: `tests/fixtures/subgroup.slang` (12 sections).

Variants and routes (M8, D139, D137): every body of a kernel is a Slang kernel of its own, with the entry point `gpu_<module>_<function>`, its own content key and its own committed `gust-artifacts/` files, and the descriptor carries only the body the build's profile selects (the largest `requires` set the profile contains); `tests/fixtures/variant.slang` is the golden of a portable and a subgroup body. The shape of a variant is its kernel's, and the stage profile validates every body whatever the build selects. A module routed to the CPU (`#[gpu(route = ..)]`, or `GUST_PROFILE=cpu`) looks up no artifact and checks no manifest in that build, and its source is validated all the same. The pinned compiler is Slang 2026.22 (`SLANG_PIN` in `toolchain.rs`; D150): artifacts built with 2026.20 fail `cargo gust check` until rebuilt.
