| D18 | Bounded loops: only `for i in start..end` with typed 32-bit integer bounds after rustc/Slang checking (T09, 2026-09-08) | A GPU thread must always terminate and must never wait on another workgroup (AGENTS). Bounds are side-effect-free in this dialect (assignments are statements, helpers are pure value functions), so hoisting the end before the start is unobservable.
