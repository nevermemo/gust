| D18 | Bounded loops: only `for i in start..end` with typed 32-bit integer bounds after rustc/Slang checking (T09, 2026-09-08) | A GPU thread must always terminate and must never wait on another workgroup (AGENTS). An exclusive range has a trip count fixed at loop entry: the end bound is evaluated once into a `__gust_end_N` temporary, the loop variable is an immutable fresh binding (`mut` patterns rejected because Slang's counter would then diverge from Rust's per-iteration binding), and the counter only increments. The macro validates the syntactic shape and the known literal-inference hazard; rustc shadows and Slang still own non-literal type checking in this proc-macro architecture. `break`/`continue` without labels or values are allowed; `return` inside the body is allowed. Bounds are side-effect-free in this dialect (assignments are statements, helpers are pure value functions), so hoisting the end before the start is unobservable. A bounded `while` needs an explicit budget contract and is future work |
