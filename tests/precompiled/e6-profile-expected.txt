# E6m, E6n and E6o of `cargo xtask check-precompiled` (m8.a, D136): the text that `cargo check -p app` must print when the
# build script of `gust` refuses a `GUST_PROFILE` value that carries a capability. One refusal per line, written
# `<case id> build-error: <text>` (the format of tests/ui/profile-unknown/expected.txt after the id). E6k
# (`native+subgroups`) and E6l (`dev+subgroups`) must compile and have no line here.
E6m build-error: gust: GUST_PROFILE `web+subgroups`: the capability subgroups is not available under the web profile in this release (the pinned wgpu cannot request it in a browser); use native or dev
E6n build-error: gust: GUST_PROFILE `cpu+subgroups`: the cpu profile takes no capability; a CPU build runs on the host and holds no GPU runtime
E6o build-error: gust: capability `f16` in GUST_PROFILE `native+f16` is not supported in this release; use subgroups
